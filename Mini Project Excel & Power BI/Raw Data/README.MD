# Healthcare Data Analytics Project

## Dataset Information

**Dataset Name:** Healthcare Dataset  
**Source:** Kaggle  
**Source Link:** https://www.kaggle.com/datasets/prasad22/healthcare-dataset  
**File Name:** healthcare_dataset.csv  
**Number of Records:** 55,500  
**Number of Columns:** 15  

## Dataset Description

The dataset contains healthcare patient and hospital admission information, including patient demographics, medical conditions, admission details, hospital information, insurance providers, billing amounts, medications, and test results.

## Project Objective

The objective of this project is to clean, transform, analyze, and visualize healthcare data using Microsoft Excel and Power BI.

## Data Pre-processing

The raw dataset will be processed using Excel for:

- Removing duplicate records
- Handling missing values
- Standardizing data formats
- Creating calculated fields
- Filtering and sorting
- Creating Pivot Tables

## Power BI Analysis

The cleaned dataset will be used to create an interactive Power BI dashboard covering:

- Patient demographics
- Medical condition analysis
- Admission trends
- Admission type
- Billing amount
- Insurance provider analysis
- Medication analysis
- Test results
- Hospital analysis
- Patient age-group analysis

## Dataset Columns

1. Name
2. Age
3. Gender
4. Blood Type
5. Medical Condition
6. Date of Admission
7. Doctor
8. Hospital
9. Insurance Provider
10. Billing Amount
11. Room Number
12. Admission Type
13. Discharge Date
14. Medication
15. Test Results
